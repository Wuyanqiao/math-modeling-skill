# 小型数值基准

这些是本项目创建的确定性合成数据，不是真实赛题或实际业务结果。用于发现基线实现回归，不证明复杂赛题正确性、实际泛化性能或论文质量。

```powershell
python "<SKILL_ROOT>/benchmarks/run_baselines.py" --output "<PROJECT_ROOT>/results/baseline-report.json"
```

依赖 numpy、scipy；分类示例测试另需 scikit-learn。脚本默认不写文件，退出码 0 表示所有数值断言通过。

| 案例 | 已知答案 | 验证设计 |
|---|---|---|
| 线性资源优化 | 最大化 3x+2y，x+y≤4、x≤2、y≤3，最优 (2,2)、值 10 | 比较解、目标值与约束余量，绝对容差 1e-9 |
| 时间顺序趋势预测 | y=3+2t，训练 t=0…9，预测 t=10…13 为 23/25/27/29 | 未来值不进入拟合，参数和预测容差 1e-9 |
| TOPSIS 评价 | 等权，一正向一负向，得分 0/0.5/1，排序 2/1/0 | 分别检查指标方向、数值、排名，容差 1e-12 |

输入固定在 `synthetic-v1.json`。报告包含种子 42（声明不使用随机采样）、输入与代码 SHA-256、版本、复现命令、数值容差、每项断言与结果 SHA-256。跨平台浮点尾数可能不同，科学验收以数值容差为准，哈希用于标识具体运行产物。

报告另含各案例及总耗时、数值成功率和 `--budget-seconds`（默认30秒）的实际达标情况。预算是观测指标，不会强制终止进程；环境安装、完整交付、快照恢复及证据覆盖在完整流程验收中单独记录，不能由三个数值小例子的通过率推断。

优化答案可独立核算：3x+2y = 2(x+y)+x ≤ 2×4+2 = 10，(2,2) 可行且达到上界。趋势数据按显式公式生成；TOPSIS 数据两列范数相等，中间方案到两个理想点等距，得分为 0.5。

分类示例通过训练内部 CV 选择参数，缩放在 Pipeline 内；调用 `evaluate_holdout` 时不重新拟合。真实数据还需依据时间、实体、空间相关性选择划分策略，不直接套默认随机 CV。
