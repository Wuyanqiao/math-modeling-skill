# 动态规划与最优控制

**何时加载**：库存、资金、设备、储能或其他“当前动作改变未来状态”的多阶段决策。先确定状态是否足够表达未来，再选 DP、MDP、最优控制或 MPC。不同求解算法与滚动求解不自动新增模型族；同一子问题最多两个独立模型体系。

## 决策合同与 Bellman 递推

记录决策时刻 $t$、状态 $s_t$、动作 $a_t\in A_t(s_t)$、信息可见性、转移 $s_{t+1}=f_t(s_t,a_t,w_t)$、阶段成本 $c_t$、终端成本 $g_T$。明确是成本最小化还是奖励最大化，定义库存交付顺序、提前期、缺货处理、贴现和终端残值。

有限时域成本递推为

$$V_T(s)=g_T(s),\qquad V_t(s)=\min_{a\in A_t(s)}\{c_t(s,a)+\mathbb E[V_{t+1}(f_t(s,a,w))]\}.$$

期望只能使用动作时可获得的分布；决策不能提前看到真实未来扰动。历史影响未来但未进入当前状态时，所谓 Markov 模型并未建立。可将必要历史、设备年龄、管道库存等纳入状态，但必须报告维数与计算预算。

| 方法 | 适用结构 | 核心检查 |
|---|---|---|
| 有限时域后向 DP | 有限状态/动作、终端条件明确 | 枚举小实例、可达状态、不可行动作、终端代价与恢复策略 |
| 值迭代 | 有限折扣 MDP | 概率行和为 1、$0\le\gamma<1$、Bellman 残差与误差界 |
| 策略迭代 | 同上，策略评估可可靠求解 | 评估当前策略再改进，处理并列最优动作；大规模评估的成本 |
| 最优控制 | 连续状态/动作和明确动力学 | 离散转写、状态/控制约束、终端条件、网格细化、最优性残差 |
| MPC | 在线滚动时域、能按时重求解 | 执行首个动作后用实测新状态重算；递归可行性、稳定性和超时回退 |

[MIT 6.231 官方课程](https://ocw.mit.edu/courses/6-231-dynamic-programming-and-stochastic-control-fall-2015/) 及[讲义目录](https://ocw.mit.edu/courses/6-231-dynamic-programming-and-stochastic-control-fall-2015/pages/lecture-notes/) 可按有限时域、值/策略迭代和最优控制专题深入，不需要整门课程预加载。

有限折扣 MDP 的 Bellman 算子为 $TV(s)=\min_a[c(s,a)+\gamma\sum_{s'}P(s'\mid s,a)V(s')]$。残差 $r=\|TV-V\|_\infty$ 给出价值误差界 $\|V-V^*\|_\infty\le r/(1-\gamma)$；它不是所有问题通用的策略损失界，也不适用于直接令 $\gamma=1$ 的平均成本/随机最短路问题。

连续最优控制可采用直接配点/多重射击，将控制和状态离散为约束优化；协态/Pontryagin 条件可以提供分析或独立验证。不同时间离散属于同一机理模型的求解层。MPC 的有限时域最优不自动保证闭环稳定，终端代价/集合、约束可行性和扰动处理需明确论证。

## 可运行例与独立检查

[dynamic-control.py](dynamic-control.py) 实现三个无外部数据的小问题：

1. **库存后向 DP**：需求 $(1,2,1)$、容量 3、期初 0、单位采购成本 2、固定下单成本 3、期末库存费 0.5、缺货罚 8。先采购后需求、零提前期、丢失销售、终端残值 0。行为测试独立穷举全部可行订单序列并比较最优成本；这里的已知需求仅为确定性算法验证。
2. **折扣 MDP**：两个状态、两个动作、$\gamma=0.9$。在状态 0 可以付 1 留在原状态，或付 0.2 到吸收状态 1；状态 1 的停留成本 0，另一个动作成本 1。解析最优值 $(0.2,0)$，策略 $(1,0)$；值迭代与策略迭代均应恢复，并报告残差。
3. **滚动控制**：$x_{t+1}=x_t+u_t$，$x_0=2$、$|u_t|\le0.6$、预测时域 3，每次最小化状态二次成本、$0.1u^2$ 与终端二次成本，只执行首个动作。测试约束、状态递推、起始饱和动作；宽松约束下与独立 Riccati 递推对照首步控制。

```powershell
python assets/algorithms/dynamic-control.py
python -m unittest discover -s tests -p test_algorithm_modules.py -v
```

需要 NumPy/SciPy。示例 MPC 仅有输入界，未提供状态约束、扰动稳定性或真实设备安全保证。升级到实际题目时增加独立滚动回测、基线策略对比、扰动/终端条件敏感性、不可行与求解超时处理。报告状态/动作网格大小、复杂度和实际耗时，不把暴力离散称为可扩展算法。
