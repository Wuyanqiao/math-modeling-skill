# 预测基线与划分

适用：观测按时间排序、目标定义稳定。先用持续值/线性趋势基线，再判断更复杂模型是否在同一回测上改进。

实现：`baselines.py::linear_trend_predict` 拟合 y=a+bt，仅接受训练时点之后的预测点；NumPy 最小二乘返回参数。已知 y=3+2t 的合成基准验证参数与未来预测，不代表真实数据泛化能力。

验证：训练/验证/测试按时间；所有缩放、插补、特征选择仅用训练窗口拟合。滚动回测记录窗口和预测距离，测试集留到方案冻结后。

风险：漂移、泄漏、未来不可得外生变量、短序列及自相关误差。含截距模型在输入零时可有非零输出；边界预期由合同定义。正则/伪逆不是病态时自动更换模型的理由。
