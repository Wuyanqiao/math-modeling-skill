# 算法目录

选方法前先读 [算法索引](../../references/算法索引.md)，按题目结构、数据与验证要求定位；不一次加载全部方法。

| 并列分类 | 主要职责 |
|---|---|
| [优化](优化/README.md) | 目标、约束、可行性、求解状态与界 |
| [预测](预测/README.md) | 基线、泛化目标、验证划分与误差 |
| [数据预处理](数据预处理/README.md) | 缺失值、编码、尺度、特征构造与无泄漏可复现管线 |
| [模型验证](模型验证/README.md) | 泛化、敏感性、不确定性、数值/约束/求解状态与机理检查 |

原有脚本与卡片路径保留兼容。数值计算、计算几何、微分方程、反问题、动态决策和不确定性优化的入口由总索引统一路由。
预处理、参数估计与模型验证是建模流程中的步骤，不按方法名称自动增加独立模型体系；每道子问题仍最多两个独立模型族。
