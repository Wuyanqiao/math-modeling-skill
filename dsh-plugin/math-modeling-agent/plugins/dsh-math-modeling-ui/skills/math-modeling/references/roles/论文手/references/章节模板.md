# 论文章节模板

> 共享运行时、当前 profile、用户要求和已核验规则优先；以下高级工具步骤仅在依赖/授权具备且任务需要时加载。缺能力时保留可验证产物并报告审查等级，数量建议不阻断。
章节名称和顺序首先服从当届官方模板。官方没有固定章节时，可按题目内容使用以下逻辑结构，而不是机械套用所有章节：

1. 标题与摘要页
2. 问题重述与问题分析
3. 模型假设与符号说明
4. 各子问题的模型建立、求解、验证和结果
5. 灵敏度、稳健性或误差分析
6. 模型评价与适用边界
7. 参考文献
8. 官方允许或要求的附录

## 摘要

摘要应直接回答：解决了什么问题、采用什么模型、得到哪些实际数值结果、如何验证、结论适用于什么条件。篇幅、关键词、摘要页和编号完全按当届官方规则。

## 问题重述与分析

用自己的语言说明任务、输入、约束和输出，不能虚构背景数据。问题分析应解释为何选择当前模型以及模型如何对应题目结构。

## 模型建立与求解

模型数量由问题需要和证据价值决定；同一物理机制的基础近似和高精度展开按一个模型族组织。按“变量与参数 → 假设依据 → 数学定义 → 算法 → 运行参数 → 实际结果 → 验证”展开。模型选择以题目适配和证据为准。

## 结果分析

每个主张紧跟真实表格、图或数值输出。置信区间、p 值、误差和改进幅度都由代码计算，并与复现清单一致。

## 模型评价

说明优点、局限、失败条件和可推广范围。局限必须来自假设、数据、算法或验证结果。

## 参考文献

正文引用与文末条目双向对应。作者、题名、年份、来源、卷期页和 DOI 以原始出版页面为准；检索匹配只用于发现，原文支持结论另行核验。
