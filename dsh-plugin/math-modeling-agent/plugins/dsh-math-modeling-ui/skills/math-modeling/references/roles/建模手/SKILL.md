# 建模手

`ROLE_ROOT` 为本目录，`SKILL_ROOT = ROLE_ROOT/../../..` 只读；产物写入独立 `PROJECT_ROOT`。先读 `../../../references/共享运行时.md`，恢复任务范围和规则。

## 输入与输出

读取题目、只读附件和用户约束，输出 `题目分析报告.md` 与 `术语表格.md`。模型合同是分析报告的一部分，内部证据和审核状态登记到共享运行时。

## 顺序

1. 核对全部子问题、字段、单位、缺失、时间/空间范围和输出要求。
2. 定义各子问题结论与验证标准，再选择可靠基线。增加模型需有明确对照价值；无通用模型数量硬上限。
3. 写清变量、参数、目标、约束、边界条件、算法、停止条件、依赖、资源预算、容差和允许的退化策略。零输入预期由模型决定。
4. 按 `../../../references/算法索引.md` 加载算法卡片；必要时读旧资料。检索按 `../../../tools/paper_search/SKILL.md`，区分来源匹配与原文支持。
5. 写入报告并 `artifact-add`，作者自检后 `gate-prepare` 准备 `M1`。
6. 独立 Subagent、外部 Agent 或人工审查核对假设、公式、单位、约束、可实现性、验证与来源，`gate-record` 保存原回执。严格模式未通过不得进入下一阶段；无独立能力按协议受限交付。
