# 数值计算基础

**何时加载**：模型没有解析解，需要求交点、把离散测量转为连续函数、计算累计量、解线性系统或反求参数。数值计算是模型内的求解工具；换二分法、Newton 法或积分精度不自动增加独立模型体系。每个子问题最多两个独立模型体系，同一物理机理的近似展开计一个模型族。

## 从问题结构选方法

| 任务 | 优先路线 | 必要条件与失败处理 |
|---|---|---|
| 标量方程 $f(x)=0$ | 有变号区间时二分/Brent；导数可靠时 Newton | 函数在区间连续；检查端点是否为根。偶重根可能不变号。Newton 可能越界、遇零导数或收敛到别的根 |
| 非线性方程组 $F(x)=0$ | `scipy.optimize.root`，可给解析 Jacobian | 缩放变量与残差；检查约束、根的物理分支、多初值稳定性，不能只读 success |
| 离散数据插值 | 线性插值、三次样条；保单调时考虑 PCHIP | 横坐标严格递增，重复观测先按测量语义处理；边界条件是模型假设，外推另立合同 |
| 离散数据积分 | 梯形；足够平滑且采样适合时 Simpson | 统一横坐标单位、排序、方向；噪声和缺测误差不由积分公式自动修复 |
| 可调用函数积分 | 自适应求积 | 分段处理不连续点、奇异点和长尾，区分求积误差与模型误差 |
| 方阵线性系统 $Ax=b$ | `solve`；稀疏/带状结构用对应求解器 | 确认秩与结构，不显式求逆；病态时同时报告后向误差与解的敏感性 |
| 超定拟合 $Ax\approx b$ | QR/SVD 最小二乘 `lstsq` | 报告秩和奇异值，避免显式构造正规方程放大条件数；有界或非线性参数转反问题卡片 |

SciPy 的模块路由见[官方用户指南](https://docs.scipy.org/doc/scipy/tutorial/index.html)；标量根的状态、区间和导数参数见 [`root_scalar`](https://docs.scipy.org/doc/scipy/reference/generated/scipy.optimize.root_scalar.html)。这里的方法选择应结合实际量纲和误差预算。

## 写入模型合同

1. 定义函数、变量范围、单位和物理可行域；说明是否寻找全部根还是某一根。
2. 定义输入来源、采样间距、噪声、缺测和允许外推范围。时间积分不能把小时误当秒。
3. 分开约定根位置误差、函数残差、相对误差与绝对误差。不同量纲的方程先无量纲化或按测量误差缩放。
4. 记录算法、初值/区间、最大迭代、停止原因、依赖版本、容差与失败后的处理。容差根据数据精度与下游结论决定。

例如求能量 $E=\int_0^T P(t)\,dt$，至少区分测量误差、插值误差、求积误差；增加采样点不等于获得新的真实观测。自然样条边界约束二阶导数，夹持样条约束一阶导数，二者都不是通用真值。默认关闭域外求值，需预测时进入预测模型验证。[CubicSpline 参数说明](https://docs.scipy.org/doc/scipy/reference/generated/scipy.interpolate.CubicSpline.html)

## 最小例与独立验证

同目录 [numerical-foundations.py](numerical-foundations.py) 只用明确的合成函数：

- 二分与 Newton 求 $x^2-2=0$ 的正根；以解析值 $\sqrt2$ 和代回残差双重核验。
- 方程组 $x+y=3,\ x^2+y^2=5$，初值选择根 $(1,2)$；另一个根 $(2,1)$ 也存在，不能报告唯一解。
- 样条恢复 $x^3$；端点导数明确为 0、3；域外返回 NaN 而非伪造预测。
- $\int_0^1x^2dx=1/3$；101 个等距点的梯形误差约 $1.67\times10^{-5}$，Simpson 达浮点误差级。
- 线性方程的解为 $(2,3)$；五点拟合 $y=2+3x$ 得截距 2、斜率 3，并报告设计矩阵秩。
