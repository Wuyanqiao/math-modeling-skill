# 预测

先读 [算法索引](../../../references/算法索引.md)，定义要推广到的新对象或未来时间范围，随后选择数据划分。

- [预测与验证卡片](../forecast-validation.md)：时间顺序、基线、误差与区间。
- [分类与参数选择](../classification-validation.md)和 [分类代码](../classification.py)：训练折内预处理和内部调参。
- [数据预处理](../数据预处理/README.md)：缺失值、类别编码、尺度变换和特征构造进入 Pipeline，先划分再拟合。
- [模型验证](../模型验证/README.md)：独立测试、分组或滚动验证，Bootstrap 与预测不确定性。
- [原预测类详解](../../02-预测类算法说明.md)：需要特定模型理论或更多例程时加载。

预测区间针对未来观测，参数或均值的置信区间不能代替预测区间。测试集不能参与缺失值、标准化、特征选择或调参。
