# 几何建模与计算几何

**何时加载**：轨迹、覆盖、布局、分区、碰撞、测量、最近邻或邻接网。先定义坐标与对象，再选空间算法；几何关系可作为一个主模型的组成，不因使用多种几何算子增加模型数量。每道子问题最多两个独立模型体系。

## 数学对象与路线

| 对象/任务 | 建模形式与方法 | 必查事项 |
|---|---|---|
| 轨迹与参数曲线 | $r(t)=(x(t),y(t),z(t))$，分段线性/样条 | 参数可能是时间、弧长或其他量，不能混用；速度、曲率需要足够可微性 |
| 坐标转换 | 刚体 $p'=Rp+t$，或明确的投影/仿射变换 | 正交矩阵应满足 $R^TR=I$；仿射变换一般不保角和距离 |
| 距离、夹角 | 欧氏范数、内积；点到线段需截断投影参数 | 零向量角度未定义；反余弦输入只对舍入误差夹到 [-1,1] |
| 相交/碰撞 | 参数方程或方向谓词；宽阶段包围盒 + 精确检查 | 直线交点不一定在线段上；平行、共线重叠、相切分别处理 |
| 凸包 | `ConvexHull` 求外包凸集 | 凹区域、孔洞和障碍物不能由凸包准确替代；二维面积字段为 `volume` |
| Voronoi 分区 | 按给定度量归属最近站点 | 需裁剪到实际边界；无限区域的顶点索引含 -1；欧氏等距不代表路程/服务时间相同 |
| Delaunay 三角剖分 | 构造邻接/插值网格 | 检查重复点、共线/共面点、退化单元和漏点；非约束剖分不会自动遵守障碍边界 |
| KD-tree | 低维空间的最近邻、半径查询 | 确认度量、单位、周期边界和 tie 规则；高维应实测，不能假设总是更快 |

[SciPy 官方空间计算教程](https://docs.scipy.org/doc/scipy/tutorial/spatial.html) 给出这些接口与 Qhull 退化情形。`QJ` 扰动点只能作为有记录的数值处理，不能默默改动实际测量或保证单元质量。

## 合同与误差

输入记录坐标参考系、长度单位、维数、测量误差、点顺序、闭合边界与是否允许重叠。经纬度角度不可直接当米；跨区域/球面问题先选适合的投影或球面距离。障碍物、孔洞、可通行区域、碰撞安全裕度都是题目约束。

将“几何精度”分为测量精度、曲线离散误差、浮点谓词容差。交叉积的容差具有长度平方单位；不要把固定 $10^{-6}$ 复制到任意尺度。边界归属与等距点采用明确规则，记录是否有多个等价答案。

对曲线求交，先定位候选区间，再解联立参数方程，并检查参数域与代回残差。参数网格没有发现交点不代表不存在：相切和窄范围交叉需要细化或解析判断。动态碰撞需检测两时刻之间的扫掠区域，不能仅比较采样帧。

## 最小例与验证

[computational-geometry.py](computational-geometry.py) 使用单位正方形四角及中心这五个确定点：

- 旋转 $\pi/3$ 再平移 $(2,-1)$，验证全部两两距离保持，误差在浮点量级。
- 两条对角线交于 $(0.5,0.5)$；线段例程显式区分无交点、端点交点与无唯一交点的共线重叠。
- 凸包面积为 1，剖分单元面积和为 1，所有单元面积为正；不要求退化情况下唯一三角剖分索引。
- 中心站点 Voronoi 区域有限；边界站点可以有无限区域，本例没有虚构裁剪后覆盖面积。
- 查询 $(0.1,0.1)$ 的最近点为原点，距离 $\sqrt{0.02}$。

```powershell
python assets/algorithms/computational-geometry.py
python -m unittest discover -s tests -p test_algorithm_modules.py -v
```

需要 NumPy/SciPy。线段函数为二维教学例，不是精确谓词几何内核；复杂 GIS、多边形拓扑或安全碰撞任务应选择领域库并验证合法性。扩展真实题目时增加坐标逆变换、旋转/平移不变性、面积守恒、解析小图、退化输入和边界覆盖测试；空间索引只缩小候选集合，不能替代题目约束。
