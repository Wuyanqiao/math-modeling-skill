# TOPSIS 评价基线

适用：候选方案、指标方向与权重都有依据，允许用相对接近理想点进行排序。排序不是因果推断。

实现：`baselines.py::topsis`，向量归一化后加权，分别构造正/负向理想点。输入为有限数矩阵、非负且总和为正的权重、每列方向；输出得分与从零起的排序索引。

验证：基准一正向一负向的对称数据应得 0/0.5/1；核对零范数列、相同加权方案、方向反转和权重敏感性。零范数或无区分度显式报错，不伪造排名。

风险：归一化改变权重含义；新增方案可能改变排序。报告方向、归一化、权重来源、稳定性，不只给最终名次。

扩展按需读 `../03-评价类算法说明.md`；AHP/熵权等权重也需验证一致性与稳定性。
